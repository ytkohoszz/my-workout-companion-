# Obsidian community plugin

## Project overview

- Target: Obsidian Community Plugin (TypeScript → bundled JavaScript).
- Entry point: `src/main.ts` compiled to `main.js` and loaded by Obsidian.
- Required release artifacts: `main.js`, `manifest.json`, and optional `styles.css`.

## Environment & tooling

- Node.js: use current LTS (Node 18+ recommended).
- **Package manager: npm** (required for this sample - `package.json` defines npm scripts and dependencies).
- **Bundler: esbuild** (required for this sample - `esbuild.config.mjs` and build scripts depend on it). Alternative bundlers like Rollup or webpack are acceptable for other projects if they bundle all external dependencies into `main.js`.
- Types: `obsidian` type definitions.

**Note**: This sample project has specific technical dependencies on npm and esbuild. If you're creating a plugin from scratch, you can choose different tools, but you'll need to replace the build configuration accordingly.

### Install

```bash
npm install
```

### Dev (watch)

```bash
npm run dev
```

### Production build

```bash
npm run build
```

## Linting

- ESLint is preconfigured with `eslint-plugin-obsidianmd` for Obsidian-specific rules.
- Run `npm run lint` to lint the project.
- A GitHub Action automatically lints every commit on all branches.

## File & folder conventions

- **Organize code into multiple files**: Split functionality across separate modules rather than putting everything in `main.ts`.
- Source lives in `src/`. Keep `main.ts` small and focused on plugin lifecycle (loading, unloading, registering commands).
- **Example file structure**:
    ```
    src/
      main.ts           # Plugin entry point, lifecycle management
      settings.ts       # Settings interface and defaults
      commands/         # Command implementations
        command1.ts
        command2.ts
      ui/              # UI components, modals, views
        modal.ts
        view.ts
      utils/           # Utility functions, helpers
        helpers.ts
        constants.ts
      types.ts         # TypeScript interfaces and types
    ```
- **Do not commit build artifacts**: Never commit `node_modules/`, `main.js`, or other generated files to version control.
- Keep the plugin small. Avoid large dependencies. Prefer browser-compatible packages.
- Generated output should be placed at the plugin root or `dist/` depending on your build setup. Release artifacts must end up at the top level of the plugin folder in the vault (`main.js`, `manifest.json`, `styles.css`).

## Manifest rules (`manifest.json`)

- Must include (non-exhaustive):
    - `id` (plugin ID; for local dev it should match the folder name)
    - `name`
    - `version` (Semantic Versioning `x.y.z`)
    - `minAppVersion`
    - `description`
    - `isDesktopOnly` (boolean)
    - Optional: `author`, `authorUrl`, `fundingUrl` (string or map)
- Never change `id` after release. Treat it as stable API.
- Keep `minAppVersion` accurate when using newer APIs.
- Canonical requirements are coded here: https://github.com/obsidianmd/obsidian-releases/blob/master/.github/workflows/validate-plugin-entry.yml

## Testing

- Manual install for testing: copy `main.js`, `manifest.json`, `styles.css` (if any) to:
    ```
    <Vault>/.obsidian/plugins/<plugin-id>/
    ```
- Reload Obsidian and enable the plugin in **Settings → Community plugins**.

## Commands & settings

- Any user-facing commands should be added via `this.addCommand(...)`.
- If the plugin has configuration, provide a settings tab and sensible defaults.
- Persist settings using `this.loadData()` / `this.saveData()`.
- Use stable command IDs; avoid renaming once released.

## Versioning & releases

- Bump `version` in `manifest.json` (SemVer) and update `versions.json` to map plugin version → minimum app version.
- Create a GitHub release whose tag exactly matches `manifest.json`'s `version`. Do not use a leading `v`.
- Attach `manifest.json`, `main.js`, and `styles.css` (if present) to the release as individual assets.
- After the initial release, follow the process to add/update your plugin in the community catalog as required.

## Security, privacy, and compliance

Follow Obsidian's **Developer Policies** and **Plugin Guidelines**. In particular:

- Default to local/offline operation. Only make network requests when essential to the feature.
- No hidden telemetry. If you collect optional analytics or call third-party services, require explicit opt-in and document clearly in `README.md` and in settings.
- Never execute remote code, fetch and eval scripts, or auto-update plugin code outside of normal releases.
- Minimize scope: read/write only what's necessary inside the vault. Do not access files outside the vault.
- Clearly disclose any external services used, data sent, and risks.
- Respect user privacy. Do not collect vault contents, filenames, or personal information unless absolutely necessary and explicitly consented.
- Avoid deceptive patterns, ads, or spammy notifications.
- Register and clean up all DOM, app, and interval listeners using the provided `register*` helpers so the plugin unloads safely.

## UX & copy guidelines (for UI text, commands, settings)

- Prefer sentence case for headings, buttons, and titles.
- Use clear, action-oriented imperatives in step-by-step copy.
- Use **bold** to indicate literal UI labels. Prefer "select" for interactions.
- Use arrow notation for navigation: **Settings → Community plugins**.
- Keep in-app strings short, consistent, and free of jargon.

## Performance

- Keep startup light. Defer heavy work until needed.
- Avoid long-running tasks during `onload`; use lazy initialization.
- Batch disk access and avoid excessive vault scans.
- Debounce/throttle expensive operations in response to file system events.

## Coding conventions

- TypeScript with `"strict": true` preferred.
- **Keep `main.ts` minimal**: Focus only on plugin lifecycle (onload, onunload, addCommand calls). Delegate all feature logic to separate modules.
- **Split large files**: If any file exceeds ~200-300 lines, consider breaking it into smaller, focused modules.
- **Use clear module boundaries**: Each file should have a single, well-defined responsibility.
- Bundle everything into `main.js` (no unbundled runtime deps).
- Avoid Node/Electron APIs if you want mobile compatibility; set `isDesktopOnly` accordingly.
- Prefer `async/await` over promise chains; handle errors gracefully.

## Mobile

- Where feasible, test on iOS and Android.
- Don't assume desktop-only behavior unless `isDesktopOnly` is `true`.
- Avoid large in-memory structures; be mindful of memory and storage constraints.

## Agent do/don't

**Do**

- Add commands with stable IDs (don't rename once released).
- Provide defaults and validation in settings.
- Write idempotent code paths so reload/unload doesn't leak listeners or intervals.
- Use `this.register*` helpers for everything that needs cleanup.

**Don't**

- Introduce network calls without an obvious user-facing reason and documentation.
- Ship features that require cloud services without clear disclosure and explicit opt-in.
- Store or transmit vault contents unless essential and consented.

## Common tasks

### Organize code across multiple files

**main.ts** (minimal, lifecycle only):

```ts
import { Plugin } from 'obsidian';
import { MySettings, DEFAULT_SETTINGS } from './settings';
import { registerCommands } from './commands';

export default class MyPlugin extends Plugin {
	settings!: MySettings;

	async onload() {
		this.settings = Object.assign(
			{},
			DEFAULT_SETTINGS,
			(await this.loadData()) as Partial<MySettings>,
		);
		registerCommands(this);
	}
}
```

**settings.ts**:

```ts
export interface MySettings {
	enabled: boolean;
	apiKey: string;
}

export const DEFAULT_SETTINGS: MySettings = {
	enabled: true,
	apiKey: '',
};
```

**commands/index.ts**:

```ts
import { Plugin } from 'obsidian';
import { doSomething } from './my-command';

export function registerCommands(plugin: Plugin) {
	plugin.addCommand({
		id: 'do-something',
		name: 'Do something',
		callback: () => doSomething(plugin),
	});
}
```

### Add a command

```ts
this.addCommand({
	id: 'your-command-id',
	name: 'Do the thing',
	callback: () => this.doTheThing(),
});
```

### Persist settings

```ts
interface MySettings { enabled: boolean }
const DEFAULT_SETTINGS: MySettings = { enabled: true };

async onload() {
  this.settings = Object.assign({}, DEFAULT_SETTINGS, await this.loadData() as Partial<MySettings>);
  await this.saveData(this.settings);
}
```

### Register listeners safely

```ts
this.registerEvent(
	this.app.workspace.on('file-open', (f) => {
		/* ... */
	}),
);
this.registerDomEvent(activeWindow, 'resize', () => {
	/* ... */
});
this.registerInterval(
	window.setInterval(() => {
		/* ... */
	}, 1000),
);
```

## Troubleshooting

- Plugin doesn't load after build: ensure `main.js` and `manifest.json` are at the top level of the plugin folder under `<Vault>/.obsidian/plugins/<plugin-id>/`.
- Build issues: if `main.js` is missing, run `npm run build` or `npm run dev` to compile your TypeScript source code.
- Commands not appearing: verify `addCommand` runs after `onload` and IDs are unique.
- Settings not persisting: ensure `loadData`/`saveData` are awaited and you re-render the UI after changes.
- Mobile-only issues: confirm you're not using desktop-only APIs; check `isDesktopOnly` and adjust.

# Obsidian Sample Plugin

This is a sample plugin for Obsidian (https://obsidian.md).

This project uses TypeScript to provide type checking and documentation.
The repo depends on the latest plugin API (obsidian.d.ts) in TypeScript Definition format, which contains TSDoc comments describing what it does.

This sample plugin demonstrates some of the basic functionality the plugin API can do.

- Adds a ribbon icon, which shows a Notice when clicked.
- Adds a command "Open modal (simple)" which opens a Modal.
- Adds a plugin setting tab to the settings page.
- Registers a global click event and outputs a Notice on click.
- Registers a global interval which logs 'setInterval' to the console.

import { Notice } from "obsidian";
import type MyWorkoutCompanionPlugin from "./main";
import type { ActiveRestTimerState } from "./types";

export type TimerTickListener = (state: ActiveRestTimerState, now: number) => void;

export class WorkoutRestTimerService {
  private plugin: MyWorkoutCompanionPlugin;
  private intervalId: number | null = null;
  private listeners = new Set<TimerTickListener>();
  private audioCtx: AudioContext | null = null;
  private lastFinishedBannerEndAt = 0;

  constructor(plugin: MyWorkoutCompanionPlugin) {
    this.plugin = plugin;
  }

  /**
   * Вызывается внутри обработчика клика пользователя (старт таймера или запись подхода),
   * чтобы разблокировать AudioContext на iOS / iPadOS.
   */
  unlockAudioOnUserGesture(): void {
    if (!this.plugin.settings.soundEnabled) return;
    try {
      const Ctx =
        window.AudioContext ||
        (window as unknown as { webkitAudioContext?: typeof AudioContext }).webkitAudioContext;
      if (!Ctx) return;
      if (!this.audioCtx) {
        this.audioCtx = new Ctx();
      }
      if (this.audioCtx.state === "suspended") {
        void this.audioCtx.resume();
      }
    } catch {
      // игнорируем, если аудио недоступно на устройстве
    }
  }

  private playCompletionChime(): void {
    if (!this.plugin.settings.soundEnabled) return;
    try {
      const Ctx =
        window.AudioContext ||
        (window as unknown as { webkitAudioContext?: typeof AudioContext }).webkitAudioContext;
      if (!Ctx) return;
      if (!this.audioCtx) {
        this.audioCtx = new Ctx();
      }
      const ctx = this.audioCtx;
      if (ctx.state === "suspended") {
        void ctx.resume();
      }

      const now = ctx.currentTime;
      const playTone = (freq: number, startOffset: number, duration: number) => {
        const osc = ctx.createOscillator();
        const gain = ctx.createGain();
        osc.type = "sine";
        osc.frequency.setValueAtTime(freq, now + startOffset);
        gain.gain.setValueAtTime(0.0001, now + startOffset);
        gain.gain.exponentialRampToValueAtTime(0.18, now + startOffset + 0.02);
        gain.gain.exponentialRampToValueAtTime(0.0001, now + startOffset + duration);
        osc.connect(gain);
        gain.connect(ctx.destination);
        osc.start(now + startOffset);
        osc.stop(now + startOffset + duration + 0.02);
      };

      playTone(659.25, 0, 0.16); // E5
      playTone(880.0, 0.18, 0.24); // A5
    } catch {
      // игнорируем ошибки аудио на заблокированном устройстве
    }
  }

  getState(): ActiveRestTimerState {
    return this.plugin.settings.timer;
  }

  getLastFinishedBannerEndAt(): number {
    return this.lastFinishedBannerEndAt;
  }

  start(sessionPath: string, durationSec: number): void {
    this.unlockAudioOnUserGesture();
    const sec = Math.max(5, Math.round(durationSec));
    const now = Date.now();
    const endAt = now + sec * 1000;
    this.lastFinishedBannerEndAt = 0;

    this.plugin.settings.timer = {
      sessionPath,
      startAt: now,
      endAt,
      durationSec: sec,
      notifiedEndAt: 0,
    };
    this.plugin.requestSaveSettings();
    this.ensureLoop();
    this.emitTick();
  }

  addSeconds(deltaSec: number): void {
    this.unlockAudioOnUserGesture();
    const t = this.plugin.settings.timer;
    const now = Date.now();
    if (t.endAt > now) {
      const nextEnd = Math.max(now + 1000, t.endAt + deltaSec * 1000);
      t.endAt = nextEnd;
      t.durationSec = Math.max(5, Math.round((nextEnd - t.startAt) / 1000));
      this.plugin.requestSaveSettings();
      this.emitTick();
    } else {
      const base = Math.max(15, deltaSec > 0 ? deltaSec : t.durationSec || 120);
      this.start(t.sessionPath, base);
    }
  }

  reset(newDefaultDurationSec?: number): void {
    const t = this.plugin.settings.timer;
    this.lastFinishedBannerEndAt = 0;
    this.plugin.settings.timer = {
      sessionPath: t.sessionPath,
      startAt: 0,
      endAt: 0,
      durationSec: newDefaultDurationSec ?? (t.durationSec || 120),
      notifiedEndAt: t.notifiedEndAt,
    };
    this.plugin.requestSaveSettings();
    this.stopLoop();
    this.emitTick();
  }

  subscribe(fn: TimerTickListener): () => void {
    this.listeners.add(fn);
    this.checkAndSyncNow();
    return () => {
      this.listeners.delete(fn);
    };
  }

  /**
   * Вызывается при старте плагина, открытии окна, а также по событиям visibilitychange / focus на iPad.
   * Не затирает молча истёкший таймер, а фиксирует завершение и уведомляет пользователя.
   */
  checkAndSyncNow(): void {
    const t = this.plugin.settings.timer;
    const now = Date.now();

    if (t.endAt > 0) {
      if (t.endAt > now) {
        this.ensureLoop();
      } else {
        const finishedEndAt = t.endAt;
        const wasNotified = t.notifiedEndAt === finishedEndAt;
        this.lastFinishedBannerEndAt = finishedEndAt;
        t.endAt = 0;
        t.startAt = 0;
        t.notifiedEndAt = finishedEndAt;
        this.plugin.requestSaveSettings();
        this.stopLoop();

        if (!wasNotified) {
          const overdueSec = Math.max(0, Math.round((now - finishedEndAt) / 1000));
          const suffix =
            overdueSec >= 5 ? ` (${overdueSec} с назад)` : "";
          new Notice(`⏰ Отдых завершён${suffix} — пора на подход!`);
          this.playCompletionChime();
        }
      }
    }
    this.emitTick();
  }

  private ensureLoop(): void {
    if (this.intervalId !== null) return;
    this.intervalId = window.setInterval(() => {
      this.checkAndSyncNow();
    }, 250);
  }

  private stopLoop(): void {
    if (this.intervalId !== null) {
      window.clearInterval(this.intervalId);
      this.intervalId = null;
    }
  }

  private emitTick(): void {
    const now = Date.now();
    const state = this.plugin.settings.timer;
    for (const fn of this.listeners) {
      fn(state, now);
    }
  }

  destroy(): void {
    this.stopLoop();
    this.listeners.clear();
    if (this.audioCtx) {
      try {
        void this.audioCtx.close();
      } catch {
        // игнорируем
      }
      this.audioCtx = null;
    }
  }
}

export function formatSecondsMMSS(sec: number): string {
  const safe = Math.max(0, Math.floor(sec));
  const m = String(Math.floor(safe / 60)).padStart(2, "0");
  const s = String(safe % 60).padStart(2, "0");
  return `${m}:${s}`;
}

  private updateTimerDisplayDOM(state: ActiveRestTimerState, now: number): void {
    if (!this.timerTimeEl || !this.timerStatusEl || !this.timerFillEl) return;

    if (state.endAt > now) {
      const remMs = state.endAt - now;
      const remSec = Math.max(0, Math.ceil(remMs / 1000));
      const totalMs = Math.max(1000, state.durationSec * 1000);
      const pct = Math.min(100, Math.max(0, (remMs / totalMs) * 100));

      this.timerTimeEl.setText(formatSecondsMMSS(remSec));
      this.timerTimeEl.className = "my-wc-timer-digits is-running";
      const endDate = new Date(state.endAt);
      const p = (n: number) => String(n).padStart(2, "0");
      this.timerStatusEl.setText(
        `Идёт отдых · до ${p(endDate.getHours())}:${p(endDate.getMinutes())}:${p(endDate.getSeconds())}`
      );
      this.timerFillEl.style.width = `${pct}%`;
      return;
    }

    const finishedAt = this.plugin.timer.getLastFinishedBannerEndAt();
    if (finishedAt > 0 && now - finishedAt < 120_000) {
      const agoSec = Math.max(0, Math.round((now - finishedAt) / 1000));
      this.timerTimeEl.setText("00:00");
      this.timerTimeEl.className = "my-wc-timer-digits is-done";
      this.timerStatusEl.setText(
        agoSec >= 3
          ? `Отдых завершён (${agoSec} с назад) — пора на подход!`
          : "Отдых завершён — пора на подход!"
      );
      this.timerFillEl.style.width = "100%";
      return;
    }

    this.timerTimeEl.setText("00:00");
    this.timerTimeEl.className = "my-wc-timer-digits";
    this.timerStatusEl.setText(`Выбран отдых: ${state.durationSec || 120} с`);
    this.timerFillEl.style.width = "0%";
  }

function migrateSettings(raw: unknown): WorkoutPluginSettings {
  const s =
    raw && typeof raw === "object"
      ? (raw as Partial<WorkoutPluginSettings>)
      : {};

  const timerRaw =
    s.timer && typeof s.timer === "object"
      ? (s.timer as Partial<ActiveRestTimerState>)
      : {};
  const timer: ActiveRestTimerState = {
    sessionPath:
      typeof timerRaw.sessionPath === "string" ? timerRaw.sessionPath : "",
    startAt: typeof timerRaw.startAt === "number" ? timerRaw.startAt : 0,
    endAt: typeof timerRaw.endAt === "number" ? timerRaw.endAt : 0,
    durationSec:
      typeof timerRaw.durationSec === "number" && timerRaw.durationSec > 0
        ? timerRaw.durationSec
        : 120,
    notifiedEndAt:
      typeof timerRaw.notifiedEndAt === "number" ? timerRaw.notifiedEndAt : 0,
  };

  const draftBySession: Record<string, SessionDraftState> = {};
  if (s.draftBySession && typeof s.draftBySession === "object") {
    for (const [k, v] of Object.entries(
      s.draftBySession as Record<string, unknown>
    )) {
      if (v && typeof v === "object") {
        const d = v as Partial<SessionDraftState>;
        draftBySession[k] = {
          selectedExKey:
            typeof d.selectedExKey === "string" ? d.selectedExKey : "",
          customWeight:
            typeof d.customWeight === "number" ? d.customWeight : 0,
          draftReps: typeof d.draftReps === "number" ? d.draftReps : 10,
          restDurationSec:
            typeof d.restDurationSec === "number" && d.restDurationSec > 0
              ? d.restDurationSec
              : 120,
        };
      }
    }
  }

  return {
    workoutsFolder:
      typeof s.workoutsFolder === "string" && s.workoutsFolder.trim()
        ? s.workoutsFolder.trim()
        : DEFAULT_SETTINGS.workoutsFolder,
    diaryFolder:
      typeof s.diaryFolder === "string" && s.diaryFolder.trim()
        ? s.diaryFolder.trim()
        : DEFAULT_SETTINGS.diaryFolder,
    soundEnabled:
      typeof s.soundEnabled === "boolean"
        ? s.soundEnabled
        : DEFAULT_SETTINGS.soundEnabled,
    pinnedSessionPath:
      typeof s.pinnedSessionPath === "string" ? s.pinnedSessionPath : "",
    selectedDay:
      typeof s.selectedDay === "number" ? s.selectedDay : 0,
    viewMode: s.viewMode === "preview" ? "preview" : "session",
    timer,
    draftBySession,
  };
}

    });

    this.registerDomEvent(document, "visibilitychange", () => {
      if (document.visibilityState === "visible") {
        this.timer.checkAndSyncNow();
      }

      this.timer.checkAndSyncNow();

      this.saveTimer = null;
      void this.saveData(this.settings);
    }, 250);

      window.clearTimeout(this.saveTimer);
      this.saveTimer = null;

const SET_LINE_REGEX =
  /-\s*\(упражнение::\s*([^)]+)\)\s*\((повторы|секунды)::\s*(\d+(?:[.,]\d+)?)\)\s*\(доп_вес_кг::\s*([\d.,]+)\)\s*\(вариант::\s*([^)]+)\)/;

const CATALOG_MAP = new Map<string, ExerciseCatalogItem>(
  EXERCISES_CATALOG.map((e) => [e.name, e])
);

export function getExerciseMeta(name: string): ExerciseCatalogItem {
  return (
    CATALOG_MAP.get(name) ?? {
      name,
      unit: "повт.",
      field: "повторы",
    }
  );
}

export function todayLocalISO(): string {
  const d = new Date();
  const p = (n: number) => String(n).padStart(2, "0");
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`;
}

export function yesterdayLocalISO(): string {
  const d = new Date();
  d.setDate(d.getDate() - 1);
  const p = (n: number) => String(n).padStart(2, "0");
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`;
}

export function currentTimeHHMM(): string {
  const d = new Date();
  const p = (n: number) => String(n).padStart(2, "0");
  return `${p(d.getHours())}:${p(d.getMinutes())}`;
}

export function isoWeekdayOf(iso: string): number {
  const parts = iso.split("-").map(Number);
  const y = parts[0];
  const m = parts[1];
  const d = parts[2];
  if (!y || !m || !d) {
    const day = new Date().getDay();
    return day === 0 ? 7 : day;
  }
  const dt = new Date(y, m - 1, d);
  const day = dt.getDay();
  return day === 0 ? 7 : day;
}

export function formatShortDateRu(iso: string): string {
  const parts = iso.split("-");
  if (parts.length !== 3) return iso;
  return `${parts[2]}.${parts[1]}`;
}

function readStr(v: unknown): string {
  return v === null || v === undefined ? "" : String(v).trim();
}

function readNum(v: unknown): number | null {
  if (typeof v === "number") return Number.isFinite(v) ? v : null;
  if (typeof v !== "string") return null;
  const s = v.trim().replace(",", ".");
  if (!s) return null;
  const n = Number(s);
  return Number.isFinite(n) ? n : null;
}

function extractISODate(v: unknown): string {
  const s = readStr(v).slice(0, 10);
  return /^\d{4}-\d{2}-\d{2}$/.test(s) ? s : "";
}

export function resolveProgramDay(
  fm: Record<string, unknown>,
  fallbackDateISO: string
): number {
  const explicit = readNum(fm[WORKOUT_KEYS.programDay]);
  if (explicit && DEFAULT_SCHEDULE[explicit]) return explicit;

  const title = readStr(fm[WORKOUT_KEYS.title]);
  if (title) {
    for (const [k, prog] of Object.entries(DEFAULT_SCHEDULE)) {
      if (prog.title === title) return Number(k);
    }
    const low = title.toLowerCase();
    const prefixes: Array<[string, number]> = [
      ["понедельник", 1],
      ["вторник", 2],
      ["среда", 3],
      ["четверг", 4],
      ["пятница", 5],
      ["суббота", 6],
      ["воскресенье", 7],
    ];
    for (const [pref, dNum] of prefixes) {
      if (low.startsWith(pref)) return dNum;
    }
  }

  return isoWeekdayOf(fallbackDateISO || todayLocalISO());
}

export function parseSetsFromContent(content: string): LoggedWorkoutSet[] {
  const sets: LoggedWorkoutSet[] = [];
  if (!content) return sets;
  const lines = content.split(/\r?\n/);

  lines.forEach((line, idx) => {
    const m = line.match(SET_LINE_REGEX);
    if (!m) return;
    const name = (m[1] ?? "").trim();
    const fieldRaw = (m[2] ?? "").trim();
    const field: ExerciseFieldKind =
      fieldRaw === "секунды" ? "секунды" : "повторы";
    const val = Number((m[3] ?? "").replace(",", "."));
    const weight = Number((m[4] ?? "").replace(",", "."));
    const variant = (m[5] ?? "").trim() || "Основной";
    if (
      name &&
      Number.isFinite(val) &&
      val > 0 &&
      Number.isFinite(weight) &&
      weight >= 0
    ) {
      sets.push({ lineIndex: idx, name, field, reps: val, weight, variant });
    }
  });

  return sets;
}

export function collectWorkoutSessions(
  app: App,
  settings: WorkoutPluginSettings
): WorkoutSessionSummary[] {
  const folderPrefix =
    normalizePath(settings.workoutsFolder || "Знания").replace(/\/+$/, "") + "/";
  const result: WorkoutSessionSummary[] = [];

  for (const file of app.vault.getMarkdownFiles()) {
    if (!file.path.startsWith(folderPrefix)) continue;
    const fm = app.metadataCache.getFileCache(file)?.frontmatter;
    const isWorkoutByFm = fm && readStr(fm[WORKOUT_KEYS.type]) === WORKOUT_TYPE_VALUE;
    const isWorkoutByName = /^Тренировка\s+\d{4}-\d{2}-\d{2}$/i.test(file.basename);
    if (!isWorkoutByFm && !isWorkoutByName) continue;

    const fallbackDate = extractISODate(
      file.basename.replace(/^Тренировка\s+/i, "")
    );
    const dateISO =
      (fm ? extractISODate(fm[WORKOUT_KEYS.date]) : "") || fallbackDate;
    const programDay = resolveProgramDay(fm ?? {}, dateISO);
    const durationMin = fm ? readNum(fm[WORKOUT_KEYS.durationMin]) : null;
    const startStr = fm ? readStr(fm[WORKOUT_KEYS.start]) : "";
    const title =
      (fm ? readStr(fm[WORKOUT_KEYS.title]) : "") ||
      DEFAULT_SCHEDULE[programDay]?.title ||
      file.basename;

    result.push({
      file,
      path: file.path,
      dateISO,
      programDay,
      durationMin,
      startStr,
      title,
    });
  }

  result.sort(
    (a, b) =>
      b.dateISO.localeCompare(a.dateISO) || b.path.localeCompare(a.path, "ru")
  );
  return result;
}

export async function hydrateWorkoutSession(
  app: App,
  summary: WorkoutSessionSummary
): Promise<HydratedWorkoutSession> {
  let content = "";
  try {
    content = await app.vault.read(summary.file);
  } catch {
    content = "";
  }
  return {
    ...summary,
    loggedSets: parseSetsFromContent(content),
  };
}

export interface PreviousExerciseReference {
  dateISO: string;
  sets: number[];
  best: number;
  lastReps: number;
  weight: number;
}

/**
 * Находит последнюю прошлую тренировку, где выполнялось это упражнение (с тем же весом или вообще),
 * чтобы предзаполнить поле повторений и показать ориентир.
 */
export async function findPreviousExerciseResult(
  app: App,
  allSessions: WorkoutSessionSummary[],
  currentSessionPath: string,
  exerciseName: string,
  targetWeight: number
): Promise<PreviousExerciseReference | null> {
  const candidates = allSessions
    .filter((s) => s.path !== currentSessionPath)
    .slice(0, 25);

  let fallbackOtherWeight: PreviousExerciseReference | null = null;

  for (const sess of candidates) {
    let content = "";
    try {
      content = await app.vault.cachedRead(sess.file);
    } catch {
      continue;
    }
    const sets = parseSetsFromContent(content).filter(
      (s) => s.name === exerciseName
    );
    if (sets.length === 0) continue;

    const exactWeightSets = sets.filter(
      (s) => Math.abs(s.weight - targetWeight) < 0.01
    );
    if (exactWeightSets.length > 0) {
      const vals = exactWeightSets.map((s) => s.reps);
      return {
        dateISO: sess.dateISO,
        sets: vals,
        best: Math.max(...vals),
        lastReps: vals[0] ?? 10,
        weight: targetWeight,
      };
    }

    if (!fallbackOtherWeight) {
      const firstWeight = sets[0]?.weight ?? 0;
      const sameFirst = sets
        .filter((s) => Math.abs(s.weight - firstWeight) < 0.01)
        .map((s) => s.reps);
      fallbackOtherWeight = {
        dateISO: sess.dateISO,
        sets: sameFirst,
        best: Math.max(...sameFirst),
        lastReps: sameFirst[0] ?? 10,
        weight: firstWeight,
      };
    }
  }

  return fallbackOtherWeight;
}

export async function ensureFolder(app: App, folderPath: string): Promise<void> {
  let current = "";
  for (const part of normalizePath(folderPath).split("/").filter(Boolean)) {
    current = current ? `${current}/${part}` : part;
    if (!app.vault.getAbstractFileByPath(current)) {
      try {
        await app.vault.createFolder(current);
      } catch {
        // уже существует
      }
    }
  }
}

export function clearManualHabitOverrideForDate(
  dateISO: string,
  habitKey: string
): void {
  try {
    const storageKey = MANUAL_HABITS_PREFIX + dateISO;
    const raw = window.localStorage?.getItem(storageKey);
    if (!raw) return;
    const parsed = JSON.parse(raw) as Record<string, unknown>;
    if (parsed && typeof parsed === "object" && habitKey in parsed) {
      delete parsed[habitKey];
      window.localStorage?.setItem(storageKey, JSON.stringify(parsed));
    }
  } catch {
    // игнорируем
  }
}

/**
 * Синхронизирует `тренировка: true` в заметку ежедневника по правилу health.js:
 * сначала ищет `Ежедневник/YYYY-MM-DD.md`, затем любую заметку в папке `Ежедневник` с `дата: YYYY-MM-DD`.
 * Если заметки за эту дату ещё нет — создаёт её.
 */
export async function syncWorkoutHabitToDiary(
  app: App,
  settings: WorkoutPluginSettings,
  targetDateISO: string
): Promise<void> {
  if (!targetDateISO) return;
  clearManualHabitOverrideForDate(targetDateISO, WORKOUT_KEYS.diaryWorkoutFlag);

  const diaryFolder = normalizePath(settings.diaryFolder || "Ежедневник").replace(
    /\/+$/,
    ""
  );
  const directPath = normalizePath(`${diaryFolder}/${targetDateISO}.md`);
  let diaryFile: TFile | null = null;

  const directAbstract = app.vault.getAbstractFileByPath(directPath);
  if (directAbstract instanceof TFile) {
    diaryFile = directAbstract;
  } else {
    const prefix = `${diaryFolder}/`;
    for (const f of app.vault.getMarkdownFiles()) {
      if (!f.path.startsWith(prefix)) continue;
      const fm = app.metadataCache.getFileCache(f)?.frontmatter;
      if (fm && extractISODate(fm[WORKOUT_KEYS.date]) === targetDateISO) {
        diaryFile = f;
        break;
      }
    }
  }

  if (!diaryFile) {
    await ensureFolder(app, diaryFolder);
    const content = [
      "---",
      `${WORKOUT_KEYS.date}: "${targetDateISO}"`,
      `${WORKOUT_KEYS.diaryWorkoutFlag}: true`,
      "---",
      "",
    ].join("\n");
    await app.vault.create(directPath, content);
    return;
  }

  await app.fileManager.processFrontMatter(
    diaryFile,
    (fm: Record<string, unknown>) => {
      fm[WORKOUT_KEYS.diaryWorkoutFlag] = true;
    }
  );
}

export async function createOrOpenWorkoutSessionFile(
  app: App,
  settings: WorkoutPluginSettings,
  dateISO: string,
  program: DayProgramSpec
): Promise<TFile> {
  const folder = normalizePath(settings.workoutsFolder || "Знания").replace(
    /\/+$/,
    ""
  );
  await ensureFolder(app, folder);
  const targetPath = normalizePath(`${folder}/Тренировка ${dateISO}.md`);
  const existing = app.vault.getAbstractFileByPath(targetPath);
  if (existing instanceof TFile) {
    await syncWorkoutHabitToDiary(app, settings, dateISO);
    return existing;
  }

  const timeNow = currentTimeHHMM();
  const lines = [
    "---",
    `${WORKOUT_KEYS.type}: ${WORKOUT_TYPE_VALUE}`,
    `${WORKOUT_KEYS.date}: "${dateISO}"`,
    `${WORKOUT_KEYS.start}: "${timeNow}"`,
    `${WORKOUT_KEYS.title}: ${JSON.stringify(program.title)}`,
    `${WORKOUT_KEYS.programDay}: ${program.dayNumber}`,
    `${WORKOUT_KEYS.durationMin}:`,
    "---",
    "",
    "## Подходы",
    "",
  ];
  const created = await app.vault.create(targetPath, lines.join("\n"));
  await syncWorkoutHabitToDiary(app, settings, dateISO);
  return created;
}

export async function appendSetToWorkoutFile(
  app: App,
  settings: WorkoutPluginSettings,
  session: HydratedWorkoutSession,
  exerciseName: string,
  repsOrSec: number,
  weightKg: number,
  variant = "Основной"
): Promise<void> {
  const meta = getExerciseMeta(exerciseName);
  const curContent = await app.vault.read(session.file);
  const prefix =
    curContent.length > 0 && !curContent.endsWith("\n") ? "\n" : "";
  const line = `${prefix}- (упражнение:: ${exerciseName}) (${meta.field}:: ${repsOrSec}) (доп_вес_кг:: ${weightKg}) (вариант:: ${variant})\n`;
  await app.vault.append(session.file, line);
  await syncWorkoutHabitToDiary(app, settings, session.dateISO || todayLocalISO());
}

export async function deleteSetFromWorkoutFile(
  app: App,
  file: TFile,
  lineIndex: number
): Promise<void> {
  const raw = await app.vault.read(file);
  const lines = raw.split(/\r?\n/);
  if (lineIndex < 0 || lineIndex >= lines.length) return;
  if (!SET_LINE_REGEX.test(lines[lineIndex] ?? "")) return;
  lines.splice(lineIndex, 1);
  await app.vault.modify(file, lines.join("\n"));
}

export function computeSessionDurationMinutes(
  startStr: string,
  fallbackMin: number | null
): number {
  if (/^\d{2}:\d{2}$/.test(startStr)) {
    const hh = Number(startStr.slice(0, 2));
    const mm = Number(startStr.slice(3, 5));
    if (Number.isInteger(hh) && Number.isInteger(mm)) {
      const now = new Date();
      const nowTotal = now.getHours() * 60 + now.getMinutes();
      const startTotal = hh * 60 + mm;
      let diff = nowTotal - startTotal;
      if (diff < 0) diff += 1440;
      if (diff > 0 && diff <= 600) return diff;
    }
  }
  return fallbackMin && fallbackMin > 0 ? fallbackMin : 60;
}

import { readFileSync, writeFileSync, existsSync } from "fs";

const targetVersion = process.argv[2] || process.env.npm_package_version;
if (!targetVersion || !/^\d+\.\d+\.\d+$/.test(targetVersion)) {
  console.error("Использование: npm run bump <версия>");
  process.exit(1);
}

const manifest = JSON.parse(readFileSync("manifest.json", "utf8"));
const { minAppVersion } = manifest;
manifest.version = targetVersion;
writeFileSync("manifest.json", JSON.stringify(manifest, null, "\t") + "\n");

const pkg = JSON.parse(readFileSync("package.json", "utf8"));
pkg.version = targetVersion;
writeFileSync("package.json", JSON.stringify(pkg, null, "\t") + "\n");

let versions = {};
if (existsSync("versions.json")) {
  try { versions = JSON.parse(readFileSync("versions.json", "utf8")); } catch { versions = {}; }
}
versions[targetVersion] = minAppVersion;
writeFileSync("versions.json", JSON.stringify(versions, null, "\t") + "\n");
console.log(`Версия успешно обновлена до ${targetVersion}`);
